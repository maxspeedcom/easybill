## 1. เริ่มต้นใช้งาน

### 1.1 เข้าสู่ระบบครั้งแรก

เปิดเว็บเบราว์เซอร์ ไปที่ URL ของระบบ เช่น `http://10.7.219.147` หรือ `http://localhost:5000`

**ข้อมูลเข้าใช้ครั้งแรก:**

| รายการ | ค่า |
|---|---|
| Username | `admin` |
| Password | `admin1234` |

> ⚠️ **สำคัญ**: เปลี่ยนรหัสผ่านทันทีหลังเข้าครั้งแรก ที่ **เมนูผู้ใช้ → แก้ไข → กรอกรหัสผ่านใหม่**

### 1.2 หน้าจอหลัก

หลังเข้าระบบจะเห็น **Dashboard** ที่แสดง:
- 🟦 **ใบเสนอราคาเดือนนี้** — ยอดรวม + จำนวน
- 🟧 **ยอดค้างชำระ** — รวมใบแจ้งหนี้ที่ยังไม่ได้รับเงิน
- 🟩 **รับชำระเดือนนี้** — ยอดรวมใบเสร็จ
- 📊 **กราฟ 14 วันล่าสุด**
- 📜 **เอกสารล่าสุด 8 รายการ**

### 1.3 แถบเมนูด้านบน

```
[Logo EasyBill] [▾ บริษัท] [หน้าแรก] [เอกสารขาย] [ลูกค้า] [สินค้า] [หมวด] [ตั้งค่า] [ผู้ใช้] [🌐 TH] [🎨] [👤]
```

- **Logo** → กลับ Dashboard
- **บริษัท ▾** → สลับ/เพิ่มกิจการ
- **เมนูหลัก 6 เมนู** → เข้าฟีเจอร์ต่างๆ
- **TH / EN** → สลับภาษา
- **🎨** → เปลี่ยนธีม / โหมดมืด
- **👤** → ออกจากระบบ

## 2. จัดการบริษัท / กิจการ

ระบบรองรับ **หลายกิจการในระบบเดียว** — ข้อมูลลูกค้า สินค้า เอกสาร แยกขาดต่อบริษัท

### 2.1 เพิ่มบริษัทใหม่

1. คลิก **dropdown บริษัท** บน top nav
2. คลิก **➕ เพิ่มกิจการใหม่** (สีเขียว)
3. กรอกข้อมูล:
   - ชื่อบริษัท (จำเป็น)
   - สาขา (default: สำนักงานใหญ่)
   - เลขประจำตัวผู้เสียภาษี (13 หลัก)
   - ที่อยู่
   - เบอร์โทร, อีเมล, เว็บไซต์
4. กด **เพิ่มบริษัท** → ระบบจะสลับมาที่บริษัทใหม่ทันที

### 2.2 สลับบริษัท

คลิก **dropdown บริษัท** → เลือกบริษัทที่ต้องการ → ระบบจะแสดง:
- เอกสารของบริษัทนั้น
- ลูกค้าของบริษัทนั้น
- สินค้าของบริษัทนั้น
- PDF จะใช้โลโก้/ลายเซ็น/ที่อยู่ของบริษัทนั้น

### 2.3 แก้ไขข้อมูลบริษัท

ไปที่ **ตั้งค่า → แท็บโปรไฟล์** → แก้ข้อมูล (ชื่อ ที่อยู่ เลขผู้เสียภาษี ฯลฯ)

### 2.4 ตั้งโลโก้และลายเซ็น

ไปที่ **ตั้งค่า → แท็บแบรนด์**
- **โลโก้บริษัท**: PNG/JPG (แนะนำ 400×400px พื้นใส)
- **ลายเซ็น (ผู้มีอำนาจ)**: PNG พื้นใส (สำหรับใส่ในเอกสาร)

## 3. ผู้ใช้งานและสิทธิ์

### 3.1 ระดับสิทธิ์

| Role | สิทธิ์ |
|---|---|
| 🛡️ **ผู้ดูแลระบบ** (admin) | เข้าได้ทุกบริษัท · ทุกฟีเจอร์ · จัดการผู้ใช้ |
| 👤 **ผู้ใช้ทั่วไป** (user) | เข้าเฉพาะบริษัทที่ได้รับสิทธิ์ · ฟีเจอร์ตามที่ admin กำหนด |

### 3.2 เพิ่มผู้ใช้ใหม่

1. เมนู **ผู้ใช้** (มีเฉพาะ admin)
2. คลิก **➕ เพิ่มผู้ใช้**
3. กรอก:
   - Username (ใช้ login)
   - รหัสผ่าน
   - อีเมล (จำเป็นถ้าจะใช้ OAuth)
   - ชื่อ-นามสกุล
   - **Role**: ผู้ดูแลระบบ หรือ ผู้ใช้ทั่วไป
4. กด **บันทึก** → ระบบพาไปหน้าแก้ไขเพื่อกำหนดสิทธิ์ต่อ

### 3.3 กำหนดสิทธิ์ผู้ใช้ทั่วไป

ในหน้าแก้ไข user (role = user) จะเห็น **2 ส่วน**:

#### 🏢 บริษัทที่อนุญาตให้เข้าใช้
- Toggle เปิด/ปิด รายบริษัท
- ผู้ใช้จะเห็นเฉพาะบริษัทที่ติ๊ก

#### 🔐 สิทธิ์รายฟีเจอร์ (19 ตัว)

| กลุ่ม | สิทธิ์ที่ตั้งได้ |
|---|---|
| **📄 เอกสาร** | ดู / สร้าง / แก้ไข / ลบ |
| **👥 ลูกค้า** | ดู / เพิ่ม / แก้ / ลบ |
| **📦 สินค้า** | ดู / เพิ่ม / แก้ / ลบ |
| **🏷️ หมวด** | ดู / จัดการ |
| **⚙️ ระบบ** | ดูตั้งค่า / แก้ตั้งค่า / จัดการผู้ใช้ / จัดการบริษัท / ดูรายงาน |

### 3.4 ระงับ / เปิดใช้ บัญชี

ในหน้ารายการผู้ใช้ คลิกไอคอน **🚫 Ban** หรือ **✓ Check** ข้างชื่อผู้ใช้

> ⚠️ ผู้ใช้ระงับบัญชีตัวเอง / ลด role ตัวเองไม่ได้ (กัน lock-out)

## 4. ตั้งค่า OAuth Login

อนุญาตให้ user เข้าระบบด้วย **Google** หรือ **Microsoft** account

### 4.1 เปิดหน้าตั้งค่า

**ตั้งค่า → แท็บ OAuth Login** (เฉพาะ admin)

### 4.2 ตั้งค่า Google OAuth

1. ไปที่ [Google Cloud Console — Credentials](https://console.cloud.google.com/apis/credentials)
2. สร้าง **OAuth 2.0 Client ID** → Application type: **Web application**
3. ในช่อง **Authorized redirect URIs** ใส่ค่าจากหน้า OAuth ของ EasyBill (กดปุ่ม **คัดลอก**)
4. กด **Create** → คัดลอก **Client ID** + **Client Secret**
5. กลับมาวางในหน้า OAuth ของ EasyBill
6. เปิด toggle **Google** → กด **บันทึก**

### 4.3 ตั้งค่า Microsoft OAuth

1. ไปที่ [Azure Portal — App registrations](https://portal.azure.com)
2. **New registration** → ตั้งชื่อ app
3. **Redirect URI** (Web) → ใส่จาก EasyBill
4. ไป **Certificates & secrets** → **New client secret** → คัดลอก **Value**
5. กลับมาวาง Client ID + Tenant + Client Secret ใน EasyBill
6. เปิด toggle → บันทึก

### 4.4 Auto-create users

เปิด toggle **🟢 สร้างบัญชีอัตโนมัติ** → user ที่ login ผ่าน OAuth ครั้งแรกจะถูกสร้างบัญชีให้อัตโนมัติ (role=user, ไม่มีสิทธิ์เข้าบริษัทใด — admin ต้องกำหนดภายหลัง)

### 4.5 หลังตั้งค่า

หน้า login จะแสดงปุ่ม **Google** / **Microsoft** ใต้ฟอร์ม

> ⚠️ **HTTPS เท่านั้น**: Google OAuth ไม่ทำงานบน HTTP (ยกเว้น localhost) — ใช้ Cloudflare Tunnel ฟรี หรือ nginx + Let's Encrypt

## 5. จัดการลูกค้า

### 5.1 เพิ่มลูกค้า

1. เมนู **ลูกค้า** → คลิก **➕ เพิ่มลูกค้า**
2. กรอก:
   - **ชื่อลูกค้า** (จำเป็น)
   - ประเภท: บริษัท / บุคคล
   - เลขประจำตัวผู้เสียภาษี
   - ที่อยู่ (ใช้ในเอกสาร)
   - เบอร์โทร, อีเมล, ผู้ติดต่อ
   - เครดิตเทอม (วัน)
3. ระบบสร้าง **รหัสลูกค้า** ให้อัตโนมัติ (C00001, C00002...) หรือกำหนดเองได้

### 5.2 ค้นหาลูกค้า

ในหน้ารายการลูกค้า — พิมพ์ในช่องค้นหา หาได้จาก:
- ชื่อ
- รหัสลูกค้า
- เลขผู้เสียภาษี
- เบอร์โทร / อีเมล

### 5.3 ลบลูกค้า

> ⚠️ ลบลูกค้าที่มีเอกสารแล้วไม่ได้ (เพื่อรักษาความถูกต้องของข้อมูลย้อนหลัง) — แต่ระงับการใช้งานได้ (toggle is_active)

## 6. จัดการสินค้าและบริการ

### 6.1 เพิ่มสินค้า

1. เมนู **สินค้า/บริการ** → **➕ เพิ่มสินค้า**
2. กรอก:
   - **ชื่อสินค้า** (จำเป็น)
   - รหัส (auto: P00001 ถ้าไม่กรอก)
   - **ประเภท**: สินค้า / บริการ
   - หน่วย (ชิ้น, ครั้ง, ชั่วโมง ฯลฯ)
   - ราคาขาย / ราคาทุน
   - **VAT**: รวม VAT / แยก VAT
   - หมวด (Category)
   - คำอธิบาย
3. บันทึก

### 6.2 หมวดสินค้า (Categories)

เมนู **หมวด** → ใช้จัดกลุ่มสินค้า เช่น:
- 🟦 บริการพัฒนาเว็บ
- 🟩 ค่าบริการรายเดือน
- 🟧 สินค้าฮาร์ดแวร์

แต่ละหมวดมีสีของตัวเอง → ใช้แสดงในรายงานและแยกประเภทรายได้

### 6.3 Autocomplete ในเอกสาร

ตอนสร้างเอกสาร — พิมพ์ชื่อสินค้าในช่องรายการ ระบบจะ **suggest** ให้ คลิกเลือก → กรอกรหัส, ราคา, หน่วย, คำอธิบาย ให้อัตโนมัติ

## 7. สร้างเอกสารขาย

### 7.1 ประเภทเอกสาร

| ตัวย่อ | ชื่อ | ใช้เมื่อ |
|---|---|---|
| **QT** | ใบเสนอราคา (Quotation) | เสนอราคาให้ลูกค้าก่อนขาย |
| **IV** | ใบแจ้งหนี้ (Invoice) | เรียกเก็บเงินหลังตกลงราคาแล้ว |
| **DO** | ใบส่งของ (Delivery Order) | ส่งของพร้อมเอกสารยืนยัน |
| **TI** | ใบกำกับภาษี (Tax Invoice) | สำหรับขอ VAT คืน / ลูกค้านิติบุคคล |
| **RC** | ใบเสร็จรับเงิน (Receipt) | ออกหลังรับเงินแล้ว |

### 7.2 ขั้นตอนสร้างเอกสาร

1. เมนู **เอกสารขาย** → เลือกประเภท (เช่น "ใบเสนอราคา")
2. คลิก **➕ สร้างใหม่**
3. กรอกข้อมูล:

   **ส่วนหัว**:
   - ลูกค้า (เลือกจาก dropdown หรือเพิ่มใหม่)
   - เลขที่เอกสาร (auto: QT-YYYYMM-XXX)
   - วันที่ออก (default: วันนี้)
   - วันครบกำหนด
   - อ้างอิง / ชื่อโครงการ

   **รายการสินค้า**:
   - คลิก **➕ เพิ่มแถว** หรือพิมพ์ใน autocomplete
   - แต่ละแถวมี: ชื่อ, รายละเอียด, รหัส, จำนวน, หน่วย, ราคา/หน่วย, ส่วนลด%, รวม
   - ลบแถวด้วยปุ่ม 🗑️

   **ยอดรวม** (คำนวณอัตโนมัติ):
   - ยอดรวมก่อนส่วนลด
   - ส่วนลดเงินสด (กรอกเอง)
   - VAT 7% (ปรับได้)
   - **ยอดสุทธิ** + คำอ่านบาทไทย

   **ส่วนล่าง**:
   - หมายเหตุ
   - เงื่อนไข (terms)
   - ช่องลายเซ็น "อนุมัติโดย" (toggle เปิด/ปิด, ตั้งวันที่)

4. คลิก **💾 บันทึก** → toast แสดง "✓ บันทึก... เรียบร้อย"

### 7.3 อนุมัติใบเสนอราคา

หลังลูกค้าตอบรับ — เปิดใบเสนอราคา → คลิก **✓ อนุมัติใบเสนอราคา** → status เปลี่ยนเป็น `accepted` พร้อมบันทึกวันที่อนุมัติ

### 7.4 แก้ไขเอกสาร

จากหน้ารายการเอกสาร → คลิก **✏️ แก้ไข** ในแถวนั้น → แก้ → บันทึก

> ⚠️ หลังออกใบกำกับภาษี (TI) แล้ว ระวังการแก้ไข — ส่งกรมสรรพากรไปแล้วอาจมีปัญหา

### 7.5 แนบไฟล์

ในหน้าแก้ไขเอกสาร — section **ไฟล์แนบ** (เปิดได้ใน Display Settings)
- อัปโหลด: PDF, รูปภาพ, doc, xlsx ฯลฯ
- ดาวน์โหลด / ลบ ได้

## 8. Workflow แปลงเอกสาร

EasyBill รองรับการ **แปลงเอกสาร** เป็นประเภทอื่น โดยใช้ข้อมูลเดิมเป็นต้นแบบ

### 8.1 Flow ปกติ

```
QT (ใบเสนอราคา)
   ↓ ลูกค้าตอบรับ
   ↓ คลิก "อนุมัติ"
IV (ใบแจ้งหนี้)
   ↓ ส่งของ
DO (ใบส่งของ)
   ↓ ลูกค้าชำระเงิน
RC (ใบเสร็จรับเงิน) + TI (ใบกำกับภาษี)
```

### 8.2 วิธีแปลง

ในหน้าดูเอกสาร (view) → คลิก **🔄 แปลงเป็น...** → เลือกประเภทปลายทาง
- ระบบจะสร้างเอกสารใหม่ คัดลอกข้อมูลลูกค้า/รายการ/ยอด
- เลขที่ใหม่ตามประเภท (เช่น IV-202505-001)
- บันทึกลิงก์ระหว่าง 2 เอกสาร — ดูประวัติเอกสารเชื่อมโยงในแท็บ "ประวัติ"

### 8.3 ทำสำเนา (Duplicate)

ในหน้าดูเอกสาร → **📋 ทำสำเนา** → สร้างเอกสารใหม่ประเภทเดียวกัน คัดลอกทุกอย่างยกเว้นเลขที่ (auto-gen ใหม่)

## 9. การพิมพ์และส่ง PDF

### 9.1 ดาวน์โหลด PDF

ในหน้าดูเอกสาร → **📥 PDF** → ดาวน์โหลดไฟล์

**คุณสมบัติ PDF:**
- 2 ภาษา (ไทย + อังกฤษ คู่กัน)
- โลโก้บริษัทมุมบนซ้าย
- เลขผู้เสียภาษีทั้งของบริษัทและลูกค้า
- ลายเซ็น "อนุมัติโดย" (เปิด/ปิดได้)
- คำอ่านยอดเงินภาษาไทย ("หนึ่งหมื่นบาทถ้วน")

## 11. Backup ข้อมูล

### 11.1 ดาวน์โหลด Backup

**ตั้งค่า → แท็บ Backup**

- **ดาวน์โหลด DB ทั้งหมด** — ไฟล์ `.db` พร้อมข้อมูลทั้งหมด
- **ดาวน์โหลดไฟล์แนบ** — zip ของไฟล์ที่ user แนบไว้

### 11.2 Backup ขึ้น Google Drive (อัตโนมัติ)

1. **ตั้งค่า → แท็บ Google Drive**
2. อัปโหลด `credentials.json` จาก Google Cloud Console (Service Account)
3. กำหนด Folder ID ใน Google Drive
4. กด **ทดสอบเชื่อมต่อ** → ถ้าผ่านระบบจะ backup ทุกวันอัตโนมัติ

### 11.3 Restore

(ต้องทำผ่าน command-line)
```bash
sudo systemctl stop thaibill
sudo cp /path/to/backup.db /opt/thaibill/instance/thaibill.db
sudo systemctl start thaibill
```

## 13. คำถามที่พบบ่อย (FAQ)

**Q: ลืมรหัสผ่าน admin ทำอย่างไร?**
A: SSH เข้าเซิร์ฟเวอร์ แล้วรัน:
```bash
cd /opt/thaibill
sudo -u thaibill venv/bin/python -c "
from app import create_app, db
from app.models import User
app = create_app('production')
with app.app_context():
    u = User.query.filter_by(username='admin').first()
    u.set_password('newpassword123')
    db.session.commit()
    print('Reset done')
"
```

**Q: ย้ายข้อมูลจากเซิร์ฟเวอร์เก่า → ใหม่?**
A: คัดลอก 2 อย่าง: `instance/thaibill.db` + `app/static/uploads/` แล้ววางในตำแหน่งเดียวกันบนเครื่องใหม่

**Q: เลขใบเสนอราคาสร้างเองได้ไหม?**
A: ได้ — กรอกในช่อง "เลขที่เอกสาร" ตอนสร้างใหม่ (default คือ auto-gen)

**Q: ลบเอกสารแล้วเลขข้ามไหม?**
A: ใช่ — เลขเอกสารใช้ sequence จึงไม่หมุนกลับ ถ้าต้องการแก้ → แก้ในฐานข้อมูลเอง (table `document_sequences`)

**Q: รองรับ Multi-currency ไหม?**
A: ระบบรองรับ 10 สกุลเงิน (THB, USD, EUR, JPY, CNY, GBP, AUD, SGD, HKD, KRW) — เลือกตอนสร้างเอกสาร

**Q: VAT 0% หรือ no VAT ตั้งได้ไหม?**
A: ได้ — ในฟอร์มเอกสาร ปรับช่อง VAT rate เป็น 0 หรือเลือก "ไม่คิด VAT"

**Q: ดูประวัติการแก้ไขเอกสารได้ไหม?**
A: ดูแท็บ **ประวัติ** ในหน้าแก้ไข — แสดง created/updated/printed

**Q: ใช้บนมือถือได้ไหม?**
A: ได้ — UI responsive รองรับมือถือ (เปิดเบราว์เซอร์ได้ทุกอย่าง)

## 14. แก้ปัญหาเบื้องต้น

### 14.1 หน้าเว็บโหลดไม่ขึ้น

```bash
# เช็คสถานะ service
sudo systemctl status thaibill

# ดู log
sudo journalctl -u thaibill -n 50

# restart
sudo systemctl restart thaibill
```

### 14.2 Login ไม่ได้

- เช็คชื่อ-รหัสผ่านใหม่
- เช็คว่า account ไม่ถูกระงับ (is_active = false)
- กดปุ่ม "แสดงรหัสผ่าน" ดูว่าพิมพ์ถูกไหม

### 14.3 OAuth ไม่ทำงาน

- เช็คว่า redirect URI ใน Google/Microsoft ตรงกับ URL จริง 100%
- ต้องเป็น HTTPS (ยกเว้น localhost)
- ลอง refresh credentials ใน Cloud Console

### 14.4 สลับบริษัทแล้วเห็นข้อมูลเก่าค้าง

- กด **Ctrl+Shift+R** → force refresh เคลียร์ cache เบราว์เซอร์
- ออกจากระบบแล้วล็อกอินใหม่

### 14.5 PDF เปิดไม่ออก / ภาษาไทยแสดงเป็นกล่อง

- เช็คว่ามีฟอนต์ Thai (Sarabun) ใน `/opt/thaibill/app/static/fonts/`
- ถ้าหาย — ดาวน์โหลดจาก [Google Fonts: Sarabun](https://fonts.google.com/specimen/Sarabun) มาวาง

### 14.6 ฟอร์มกดบันทึกแล้วไม่ทำงาน

- เปิด Developer Console (F12) → ดูแท็บ Console ว่ามี JS error ไหม
- เช็คว่าเลือกลูกค้าแล้ว
- เช็คว่าใส่อย่างน้อย 1 รายการ
- ส่ง screenshot ของ Console error มาให้ผู้พัฒนาได้
