🔧 ตั้งค่า Sign in with {{ provider_name }}

ฟีเจอร์ Sign in with {{ provider_name }} ยังไม่ได้เปิดใช้งาน — ต้องตั้งค่า OAuth Client ก่อน

⚠️ ข้อจำกัด: OAuth ต้องการ HTTPS (ยกเว้น http://localhost) ถ้าระบบรันที่ http://10.7.219.147 ตรงๆ จะใช้ไม่ได้ — ต้องตั้ง reverse proxy + SSL cert หรือใช้บริการ tunnel (เช่น Cloudflare Tunnel)

วิธีตั้งค่า:

{% if provider == 'google' %}
  1. เปิด Google Cloud Console — Credentials
  2. สร้าง OAuth 2.0 Client ID
    • Application type: Web application
    • Authorized redirect URIs: https://your-domain/login/google/callback
  3. คัดลอก Client ID และ Client Secret
  4. เพิ่มลง /opt/thaibill/.env:
    GOOGLE_CLIENT_ID=xxxxx.apps.googleusercontent.com GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxx
  5. Restart service: sudo systemctl restart thaibill
{% else %}
  1. เปิด Azure Portal — App registrations
  2. สร้าง New registration
    • Supported account types: Accounts in any organizational directory and personal Microsoft accounts
    • Redirect URI: Web → https://your-domain/login/microsoft/callback
  3. ไป Certificates & secrets → New client secret
  4. คัดลอก Application (client) ID และ Client secret Value
  5. เพิ่มลง /opt/thaibill/.env:
    MS_CLIENT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx MS_CLIENT_SECRET=xxxxxxxxxxx MS_TENANT=common
  6. Restart service: sudo systemctl restart thaibill
{% endif %}
💡 หมายเหตุ: หลังตั้งค่า OAuth — ผู้ใช้ที่ login ด้วย Google/Microsoft ต้องมีบัญชีที่ username หรือ email ตรงกับอีเมลของ provider อยู่ในระบบก่อน (ระบบไม่สร้างบัญชีอัตโนมัติ — admin ต้องเพิ่มผู้ใช้ก่อน)
