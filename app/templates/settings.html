📖 วิธีตั้งค่า Service Account

  1. เปิด Google Cloud Console
  2. สร้าง Project ใหม่ (หรือใช้ที่มี)
  3. เมนู "APIs & Services" → "Library" → ค้นหา Google Drive API → กด Enable
  4. เมนู "IAM & Admin" → "Service Accounts" → Create service account
    • ตั้งชื่อ เช่น thaibill-backup
    • กด Create → Done
  5. คลิกที่ Service Account ที่สร้าง → Keys → Add Key → Create new key → เลือก JSON → Create → จะดาวน์โหลด JSON file
  6. ไปที่ Google Drive → สร้าง/เลือกโฟลเดอร์ที่จะเก็บ backup → คลิกขวา → Share
  7. วาง email ของ Service Account (จาก JSON, field client_email) → ตั้งสิทธิ์ Editor → Send
  8. กลับมาที่นี่: ใส่ Folder ID + อัปโหลด JSON file → กดบันทึก → กด "ทดสอบ"
JSON key จะเก็บใน instance/gdrive/ ของ server เท่านั้น ไม่ถูก commit
