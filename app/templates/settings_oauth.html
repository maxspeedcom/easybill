Sign in with Google

{% if config.google_enabled and config.google_client_id and config.google_client_secret %} ✓ เปิดใช้งาน {% else %} ปิด {% endif %}
  1. เปิด Google Cloud Console — Credentials
  2. สร้าง OAuth 2.0 Client ID → Application type: Web application
  3. เพิ่ม Authorized redirect URIs ด้านล่างนี้:
    {{ google_redirect }}
  4. คัดลอก Client ID และ Client Secret มาวางข้างล่าง

Sign in with Microsoft

{% if config.ms_enabled and config.ms_client_id and config.ms_client_secret %} ✓ เปิดใช้งาน {% else %} ปิด {% endif %}
  1. เปิด Azure Portal — App registrations
  2. สร้าง New registration
  3. เพิ่ม Redirect URI (Type: Web) ด้านล่าง:
    {{ ms_redirect }}
  4. ไป Certificates & secrets → สร้าง New client secret → เก็บค่า Value
